# Notification Function {#notification-function}

<p class="doc-lead">This section explains the email notification features.</p>

#### 1.  Email Server Configuration (Required Prerequisite) {#1-email-server-configuration-required-prerequisite}

* To use the email notification function, the [Email Server settings](./preferences/server-and-service-integration-settings.md) must first be configured in the Preferences menu.

#### 2. Configuring Email Reception Settings {#2-configuring-email-reception-settings}

* Click on your User Information (Profile icon) on the top right, then select \[Profile Settings]. In the

![](/img/clarity-sc-en/image-103.png)

* Mail Reception section, you can enable or disable email notifications.

![](/img/clarity-sc-en/image-104.png)

<mark style="background-color:rgba(255, 214, 0, 0.35)">※</mark> <mark style="background-color:rgba(255, 214, 0, 0.35)">Once both of the above settings are complete, the following email notifications will be sent</mark>

**CVE Notifications**

* If a new CVE is identified in a project, a notification email is sent to the project creator and members.
* These notifications are sent in English.

![](/img/clarity-sc-en/image-102.png)

**Project Verification Workflow Notifications**

* A notification email is sent to the project creator and members each time the verification workflow progresses to a new stage.
* These emails are sent in the language selected by the user.

![](/img/clarity-sc-en/image-101.png)
